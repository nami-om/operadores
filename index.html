Operadores JavaScript

Os operadores são usados para atribuir valores, comparar valores, executar operações aritméticas e muito mais.

1. Operadores Aritméticos

Operador Descrição Exemplo (y = 5)
+ Adição x = y + 2 (x = 7)
- Subtração x = y - 2 (x = 3)
* Multiplicação x = y * 2 (x = 10)
/ Divisão x = y / 2 (x = 2.5)
% Módulo (Resto da divisão) x = y % 2 (x = 1)
** Exponenciação x = y ** 2 (x = 25)

2. Operadores de Atribuição

Operador Exemplo Equivalente a
= x = y x = y
+= x += y x = x + y
-= x -= y x = x - y

3. Operadores de Comparação

Operador Descrição Exemplo
== Igual a (valor) 5 == "5" (true)
=== Estritamente igual (valor e tipo) 5 === "5" (false)
!= Diferente 5 != 8 (true)
> Maior que 5 > 2 (true)

4. Operadores Lógicos

Operador Descrição Exemplo (se x=6, y=3)
&& E (AND) lógico (x < 10 && y > 1) é true
|| OU (OR) lógico (x == 5 || y == 5) é false
! NÃO (NOT) lógico !(x == y) é true
